# Online store
Проект интернет-магазина, который выводит страницы: Главную, Каталога, Контактов, собирает данные номера, имени клиента 
и произвольное сообщение и возвращает приветственное сообщение. Статус: в разработке. Процент покрытия тестами:_.

## Технологии
- База данных: Postgresql
- Frontend: HTML, (static files: CSS, JavaScript)

## Использование
Клонируйте репозиторий с помощью команды:
```sh
git clone https://github.com/Oks-anaK/Djangoproject.git
```

## Разработка
1. Модуль [models.py](catalog/models.py) содержит модели Product, Category.
2. Здесь [urls.py](catalog/urls.py) маршрутизация проекта.
3. [views.py](catalog/views.py) - контроллеры.
4. [admin.py](catalog/admin.py) - административная панель.
5. [templates](catalog/templates) - шаблоны html.

### Установка зависимостей
Для установки зависимостей, выполните команду:
```sh
poetry install
poetry shell
```
